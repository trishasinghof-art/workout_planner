# BodySync

## Overview

BodySync is a web-based fitness planning application that generates personalized workout routines and meal suggestions based on user-defined goals and preferences. The application provides a structured approach to daily fitness planning through a simple and interactive interface.

## Features

* Accepts user input for fitness goals and basic preferences
* Generates daily workout routines with exercises, sets, and structure
* Provides meal suggestions based on selected diet type
* Secure user authentication using Firebase

## Technologies Used

* React
* JavaScript
* CSS
* Firebase (Authentication)
* Vite

## How to Use

1. Open the application
2. Sign in using the authentication system
3. Enter your fitness details and preferences
4. View the generated workout plan and meal suggestions

## Notes

* The application is client-side rendered using React
* Firebase is used solely for authentication
